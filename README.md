# StudyBuddy (fictional demo app)

StudyBuddy is a **fictional** app that matches high school students with study
partners and chats with them through an AI assistant. It is not a real product,
and every name, number, and student in it is made up.

This repository exists as a test target for responsible-AI scanners, built for
SpartHill Hacks 2026. It contains **deliberately planted problems** in its code
and its landing page, so a scanner has something real to find. Don't use any of
it as an example of how to build an app.

- `index.html`: the landing page (published with GitHub Pages)
- `app/`: the Python backend (signup, partner matching, AI chat, and a tool-using agent)
- `src/`: React components for the web app
